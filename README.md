# 像素实验室 · 数字图像处理

数字图像处理教学演示网站的静态发布文件，面向 GitHub Pages。

包含课件原图、27 项交互实验、浏览器内实际执行的 Python、逐行代码解释、前后滑动对比、像素与误差分析、会话记录和实验报告。

图片在访问者本地浏览器处理；无应用后端。Python 运行环境及图像处理依赖随站点提供，首次使用需等待初始化。

课程依据与图片来源：刘兴庭《数字图像处理》第 2—4 章课件。图片来源页码、代码适配说明在网站内标注。界面依赖的开源许可证见 `licenses/ui.txt`。

更新发布：在源项目完成构建后，将 `dist` 内容更新到本仓库根目录，并保留 `.nojekyll`；推送 `main` 分支后由 GitHub Pages 发布。
